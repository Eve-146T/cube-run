2.4 Release Notes

- Accessibility: Duck Obstacles now have arrows on them showing you that you have to duck instead of jump
- New Cube Abilities! The ghost cube can now phase through one obstacle per run, and the Bubblegum cube now has a 35% chance to not consume a bubble when you use one.
- Added a new matrix themed easter egg
- added a new upgrade to start runs with a faster speed
- Balance changes and UI Improvements (including a new start up animation and a new icon), and the ability to pick up Cube Shards during runs.
